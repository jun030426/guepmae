# P1 실거래 데이터 적재와 자동 갱신

대상: `jun030426/guepmae`, Supabase `oormfipegcfbhvctikfl`, `guepmae.vercel.app`. 다른 프로젝트에는 적용하지 않습니다.

## 변경

- 운영 DB의 개별 거래 0행·시세 추이 0행·단지 가격 4,000행 상태를 확인했습니다. 이전 데이터는 로컬 비공개 백업에 보존했습니다.
- 현재 국토부 시도/시군구 목록으로 2023-10~2026-09의 36개월을 수집했습니다. 256개 시군구 × 36개월 = 9,216개 요청 단위가 모두 완료됐습니다.
- 수집 원본 1,504,078건 중 해제 84,395건과 직거래 122,170건을 제외했습니다. 판정용 중개거래 1,297,513건, 단지×면적 79,645행, 지역×면적대×월 추이 12,083행입니다. 가격 추이는 거래가 있는 달의 실제 중앙값이며 빈 달을 추정하지 않습니다.
- 같은 구 안의 동명 아파트를 공식 아파트 일련번호로 분리합니다. 이름이 겹치면 위치·식별자를 붙여 단지 선택과 서버 판정이 같은 대상을 사용하도록 했습니다.
- 매물 목록과 승인은 변경하지 않습니다. 실제 매물은 0건으로 유지합니다. 매물 상세는 동일 단지 개별 거래를 읽어 면적별 요약·최근 계약·월별 중앙값을 표시하며, 저장된 승인 당시 기준가를 임의로 바꾸지 않습니다.
- 하이브리드 단지 검색·시세·리포트는 DB에서 읽습니다. 리포트는 같은 수집 자료의 최근 12개월(482,193건)을 사용하며, 화면에 판정용 자료의 기간·건수도 표시합니다.
- 비공개 스테이징에 모든 행을 올린 뒤 한 트랜잭션에서 네 테이블을 교체합니다. 해시/건수 불일치·지역/월 누락·20% 초과 행 감소·버전 역행·DB 오류가 있으면 공개 데이터 교체를 거부합니다. 원본 캐시도 성공 후에만 교체합니다.

## 실행

원본과 비밀키는 Git에서 제외합니다. 운영 대상은 업로더에서 급매 프로젝트로 고정합니다.

1. `node --env-file=.env.local scripts/publish-market-dataset.mjs download`
2. `python scripts/fetch-market-trades.py --env-file .env.local --refresh-months 3`
3. `node --max-old-space-size=4096 scripts/build-market-dataset.mjs`
4. `node --env-file=.env.local scripts/publish-market-dataset.mjs check`
5. 검증 후 `node --env-file=.env.local scripts/publish-market-dataset.mjs publish`

첫 수집은 1을 생략합니다. 실패 구간만 이어받을 때는 같은 실행의 체크포인트에 `--resume`을 사용합니다. 이전 리포트 원본은 `--seed-report <폴더>`로 해시와 완료 기록을 확인한 뒤 재사용할 수 있습니다.

GitHub Actions는 `MOLIT_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY` 두 저장소 시크릿을 사용합니다. `SUPABASE_URL`은 워크플로에서 급매로 고정합니다. 예약 실행은 `TRADES_REFRESH_ENABLED=true`로 활성화하며 한국 03:30에 최근 3개월을 다시 수집합니다. 수동 `dry_run=true`는 DB/Storage 쓰기를 하지 않습니다. `months=0`은 저장된 원본으로 실제 러너를 검증할 때, `months=36`은 오래된 해제 신고까지 전량 갱신할 때 사용합니다.

현재 갱신 방식은 DB를 직접 서빙하므로 매일 번들을 커밋하거나 Vercel을 재배포하지 않습니다. 로컬 데모 번들은 별도의 고정 스냅샷입니다. 이전 시도별 CSV 파이프라인과 혼용하지 않습니다.

## 검증

- Node 217개, Python 수집기 8개 테스트 및 운영 빌드 통과.
- 별도의 Python CSV 계산으로 원본·해제·직거래·36개월 판정 거래·12개월 리포트 합계 일치 확인.
- PGlite에서 실제 SQL을 실행해 미완성 적재 거부, 교체 도중 오류의 전체 롤백, 익명·일반회원의 스테이징/발행 차단, 이전 버전 거부를 확인.
- 운영 DB 적재 후 공개 API의 79,645/79,645/12,083행 및 1,297,513건 합계를 확인했습니다. 익명 스테이징 조회·발행 RPC는 거부됩니다. 발행 함수에만 60초 제한을 적용했고 일반 조회 제한은 유지합니다.
- 기존 번들에 없던 아남1(서울 종로구)을 브라우저에서 검색·선택했습니다. 84㎡·12층 입력으로 17건의 중층 12개월 중앙값 11억 9,000만원이 표시되며, 실제 저장 API도 같은 기준가를 산출합니다. 상세의 51건 거래 요약·20건 최근 계약·월별 추이 표시 및 콘솔 오류 없음을 확인했습니다.
- 자동 실행은 배포 후 GitHub Actions의 수동 dry run으로 실제 러너까지 확인한 뒤 활성화합니다. 결과는 저장소 Actions 실행 기록에서 확인합니다.
